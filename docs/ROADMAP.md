# Roadmap

The 0.1.0 foundation intentionally stops at the safest useful Word workflow.

Next priorities:

1. Native Windows Credential Manager and macOS Keychain credential stores.
2. Real provider-specific OAuth flows only where the provider documents and permits third-party use.
3. Rich Word target anchors that survive more document movement than paragraph index plus fingerprint.
4. Comments, formatting proposals, and Track Changes behind capability detection.
5. Persisted conversation/session history with explicit privacy controls.
6. Packaged Windows background service and signed Office add-in deployment.
7. Excel, PowerPoint, and Outlook adapters on top of the same shared agent/provider core.
